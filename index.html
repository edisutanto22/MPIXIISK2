📖 Glosarium

Bandwidth
Kapasitas maksimum data yang dapat dikirim per detik.
DHCP
Layanan pemberi alamat IP otomatis.
DNS
Sistem penerjemah nama domain menjadi alamat IP.
Gateway
Titik keluar jaringan menuju jaringan lain, biasanya router.
HTTP/HTTPS
Protokol web; HTTPS terenkripsi.
IP Address
Alamat logis perangkat dalam jaringan.
ISP
Penyedia layanan internet.
MAC Address
Alamat fisik unik 48 bit pada NIC.
Paket
Potongan data berisi header dan isi yang dikirim lewat jaringan.
Protokol
Aturan komunikasi antar perangkat.
Latency
Waktu tunda pengiriman data (ping).
Subnetting
Membagi jaringan besar menjadi subjaringan lebih kecil.
